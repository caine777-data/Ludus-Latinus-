# Illustrations de tête de leçon, 5e (mondes 1 à 10)

Proposition de l'architecte (17/10/2026). 39 images : une par leçon de cours (types `quiz`, `trou`, `puzzle`, `decodeur`), les arènes sont exclues. Même style que les illustrations de 4e et de 3e.

- Générer chaque image avec le prompt du bloc de code, en format **16:9**.
- Télécharger les images dans l'ordre du document, sans les renommer : l'architecte les retrouve par la date de téléchargement et vérifie chacune.
- Aucun texte, lettre ou chiffre dans les images ; si un enfant apparaît, aucun âge n'est donné.
- Neuf leçons de 5e affichent aujourd'hui une image du musée choisie d'après leur titre. Leur nouvelle image la remplacera.
