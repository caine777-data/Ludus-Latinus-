# Illustrations de tête de leçon, 4e et 3e (mondes 11 à 26)

Proposition de l'architecte (15/10/2026). 48 images : une par leçon de cours (types `quiz`, `trou`, `puzzle`, `decodeur`), les arènes sont exclues. Chaque image illustre le récit ou une scène romaine liée à la leçon, jamais un tableau ni une écriture.

- Générer chaque image dans Gemini avec le prompt du bloc de code.
- Nom de fichier : `lecon_mXX-YY.jpg` (par exemple `lecon_m11-01.jpg`), à déposer dans `gemini ludus`.
- Format paysage 3:2, affiché en bandeau de 140 points de haut : sujet centré, décor flou.
- Aucun texte, lettre ou chiffre dans les images ; si un enfant apparaît, aucun âge n'est donné.
