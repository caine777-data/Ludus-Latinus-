# Illustrations des leçons complémentaires

Proposition de l'architecte (18/10/2026). 6 images, une par leçon complémentaire (mondes 17 à 25). Même style que les autres illustrations de leçon.

- Générer chaque image avec le prompt du bloc de code, en format **16:9**.
- Télécharger les images dans l'ordre du document, sans les renommer : l'architecte les retrouve par la date de téléchargement et les convertit en WebP.
- Aucun texte, lettre ou chiffre dans les images.
- Ces leçons attendent encore la validation de leur contenu : si une leçon change, son image pourra changer aussi.
